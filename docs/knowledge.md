# 知识库

> Career Kit 本地知识库结构说明

## 目录结构

```
data/knowledge/
├── resumes/       # 参考简历
├── jds/           # 收集的 JD
├── interviews/    # 面经
└── market/        # 市场数据
```

## 目录说明

### resumes/ - 参考简历

存放同背景前辈的简历、简历模板。

**示例文件**：
- `双非前端转AI.md` - 同背景前辈的简历参考
- `211后端字节.md` - 目标公司前辈的简历

### jds/ - 收集的 JD

存放目标岗位的职位描述。

**示例文件**：
- `字节_Agent开发.md` - 目标岗位 JD
- `携程_实习.md` - 实习岗位 JD

### interviews/ - 面经

存放面试经验、面试题。

**示例文件**：
- `字节_Agent_一面.md` - 面试经验
- `Agent开发_高频题.md` - 整理的高频面试题

### market/ - 市场数据

存放行业趋势、薪资数据、技能图谱。

**示例文件**：
- `AI岗薪资2025.md` - 薪资数据
- `Agent技能图谱.md` - 技能要求总结

## 支持的文件格式

- `.md` - Markdown 文本
- `.txt` - 纯文本
- `.json` - JSON 数据

## 使用方式

1. 将收集的资料放入对应目录
2. 系统在进行差距分析时会自动检索这些文件
3. 文件名建议包含关键词（如 `字节_Agent开发_面经.md`），便于匹配

## 与企业库的关系

- **企业库**（`src/scrapers/`）：自动抓取的企业数据
- **知识库**（`data/knowledge/`）：用户积累的求职资料

两者互补，系统会优先检索知识库，然后用企业库补充。
