## 方向一：LLM Prompt 和工作流调优

### 1.1 输出格式解析不稳定 ⚠️

**现状**：`gap_analyzer.py` 用正则从 markdown code block 提取 JSON

**问题**：LLM 输出格式不稳定，解析失败时只能返回 raw 文本

**建议**：
- 在 prompt 中强化**输出格式约束**
- 实现**多策略解析**：先尝试 JSON，再尝试正则提取关键字段
- 添加**重试机制**：解析失败时让 LLM 重新格式化

**优先级**：P0 | **工作量**：中

> sop_executor.py 已被 methodology.py 替代（只加载 YAML 返回上下文，不再做模板拼接和步骤执行）。

---

### 1.2 方法论缺少分支和循环 ⚠️

**现状**：方法论 YAML 是线性的（phases 顺序执行），不支持条件分支和循环

**问题**：无法根据中间结果调整后续指引

**建议**：
- 支持**条件分支**：`if persona.experience_level == "应届" then ...`
- 支持**循环**：`for each skill_gap ...`
- 实现**动态方法论**：根据用户画像选择不同的指引路径

**优先级**：P2 | **工作量**：大

---

### 1.3 缺少 Prompt 版本管理 ⚠️

**现状**：Prompt 模板硬编码在 YAML 文件中，无法版本控制

**问题**：优化 prompt 时无法回滚，无法 A/B 测试

**建议**：
- 支持**多版本 prompt**：`resume_screening_v1.yaml`、`resume_screening_v2.yaml`
- 实现**prompt 模板继承**：基础模板 + 公司定制模板
- 添加**prompt 性能追踪**：记录哪个版本的分析更准确

**优先级**：P2 | **工作量**：中
