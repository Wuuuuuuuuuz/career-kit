# BOSS直聘 使用指南

## 用途

搜索 BOSS直聘（zhipin.com）的真实岗位数据，含明确的薪资范围——这是薪资行情分析的首选数据源。

## 参数

| 参数 | 必填 | 说明 |
|------|------|------|
| keyword | 是 | 搜索关键词，如 `"Python"`、`"AI Agent"` |
| city | 否 | 城市名（`"北京"`、`"上海"`、`"全国"`）或城市代码 |
| experience | 否 | 经验要求，如 `"1-3年"`、`"3-5年"`、`"不限"` |
| degree | 否 | 学历要求，如 `"本科"`、`"硕士"`、`"不限"` |
| salary | 否 | 薪资范围，如 `"15-25K"`、`"30-50K"` |
| limit | 否 | 返回数量上限，默认 20 |

## 调用示例

```
fetch_company_jobs(company="boss", params='{"keyword":"AI Agent", "city":"上海", "limit":10}')
```

## 返回字段

| 字段 | 说明 |
|------|------|
| title | 岗位名称 |
| url | 详情页链接（可传给 fetch_jd_detail） |
| location | 工作地点 |
| salary | 薪资范围（该源的特色字段） |
| summary | 岗位摘要 |

## 注意事项

1. **需要登录态**：首次使用前在本项目目录运行 `python -m src.scrapers.boss.login`，
   一条命令到底：patchright（Playwright 反检测 fork，驱动层消除 CDP 检测向量）
   拉起**系统默认浏览器（Chrome 或 Edge）** → 你在浏览器完成扫码 → 工具自动检测
   登录态落盘并退出，全程无需任何手动确认；cookies 长期复用，过期时重跑一次即可
2. **浏览器原则**：登录只使用 Chrome / Edge，**绝不回退 Chromium**——
   开源内核的自动化指纹太明显，BOSS 一测一个准；未装 Chrome/Edge 时工具会
   明确报错而不是静默降级。窗口尺寸**由浏览器自适应**（仅 --start-maximized，
   由操作系统最大化到实际工作区），代码不规定任何分辨率——强制尺寸不是
   看不全就是超出可视区域
2. 失败时错误信息会说明原因（未登录 / 风控 code=36 需等待 / code=37 自动处理 stoken）
3. 抓取频率受风控限制，短时间多次调用可能被临时限制
4. `salary` 过滤为**近似过滤**：BOSS API 对日薪岗（如「250-400元/天」）不生效，
   结果中可能混入日薪岗位
